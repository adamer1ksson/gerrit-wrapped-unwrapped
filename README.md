# Gerrit Insights

Create an application that is called "Gerrit Wrapped" that is supposed to have a somewhat similar look and feel as Spotify wrapped. The application should be mainly built for mobile devices, and should have a dropdown where you can pick between the Gerrit Wrapped of 5 users called: "Adam", "Christian", "Nima", "Dilan" and "Theo". The users' wrapped should all contain the data for the following metrics: Number of git commits, number of merges, number of lines added, number of reviews made, most edited file, Most used AI-tag, Most targeted Jira Ticket. Those are all the stats. You can create fake data for now, but keep the data as simple data structures in the code so I easily can input them later when I get the data. The dropdown is where you choose to see an individual:s stats, but there should also be a main page, that is the landing page, that shows all the users results side by side for each category, so you can compare who got the most commits, merges, etc. Create this application
